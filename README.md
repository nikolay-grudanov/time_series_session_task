# Telegram-бот для прогнозирования акций

## Обзор проекта

Это Telegram-бот на основе Python, который анализирует и прогнозирует цены акций с использованием моделей временных рядов. Бот позволяет пользователям ввести символ тикера компании и сумму инвестиций, затем автоматически загружает исторические данные акций, обучает несколько моделей временных рядов, выбирает лучшую модель и генерирует прогноз на следующие 30 дней.

### Ключевые особенности

- **Взаимодействие с пользователем**: Принимает символы тикеров компаний и суммы инвестиций через Telegram
- **Получение данных**: Загружает исторические данные акций с помощью `yfinance` из Yahoo Finance
- **Обучение моделей**: Реализует несколько типов моделей:
  - Классические ML-модели (Random Forest, Ridge Regression с лаговыми признаками)
  - Статистические модели (ARIMA, ETS, Prophet)
  - Нейронные сети (LSTM, GRU, RNN)
- **Выбор модели**: Автоматически выбирает лучшую модель на основе показателей эффективности (RMSE, MAPE, MAE)
- **Прогнозирование**: Генерирует 30-дневные прогнозы цен с доверительными интервалами
- **Визуализация**: Предоставляет графическое представление исторических и прогнозируемых цен
- **Торговые рекомендации**: Определяет оптимальные дни для покупки/продажи и рассчитывает потенциальную прибыль
- **Логирование**: Ведет журнал всех пользовательских запросов с ключевыми параметрами
- **Интернационализация**: Полная поддержка русского и английского языков

### Доступные команды

| Команда | Описание |
|---------|----------|
| `/start` | Начать работу с ботом, выбрать язык интерфейса |
| `/lang` | Изменить язык интерфейса |
| `/help` | Показать справку по использованию бота |
| `/stocks` | Показать список доступных акций |
| `/forecast <TICKER> <AMOUNT>` | Получить прогноз (например: `/forecast AAPL 1000` или `AAPL 1000`) |
| `/model_status` | Показать статус модели |

## Интернационализация (i18n)

Бот поддерживает интерфейс на русском и английском языках.

### Поддерживаемые языки

| Код | Язык | Статус |
|-----|------|--------|
| `ru` | Русский | ✅ Полная поддержка |
| `en` | Английский | ✅ Полная поддержка |

### Структура модуля i18n

```
src/i18n/
├── __init__.py          # Экспорт публичного API
├── constants.py         # Перечисление MessageKey для всех сообщений
├── loader.py            # MessageLoader - загрузка переводов
└── middleware.py        # LanguageMiddleware - управление языком пользователя
```

### Как добавить новое сообщение

1. Добавьте ключ в `src/i18n/constants.py`:
   ```python
   class MessageKey(str, Enum):
       new_message_key = "new_message_key"
   ```

2. Добавьте переводы в `locales/ru.json` и `locales/en.json`:
   ```json
   {
     "new_message_key": "Текст сообщения на русском",
     ...
   }
   ```

3. Используйте в коде:
   ```python
   from src.i18n.constants import MessageKey
   from src.i18n.loader import MessageLoader

   loader = MessageLoader()
   text = loader.get(MessageKey.new_message_key, language)
   ```

## Начало работы

1. Клонируйте репозиторий
2. Установите зависимости с помощью uv:
   ```bash
   uv sync
   ```
3. Создайте файл `.env` с токеном вашего Telegram-бота:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_бота_здесь
   ```
4. Запустите бота:
   ```bash
   python src/main.py
   ```

Для получения подробных инструкций по настройке см. [Руководство по настройке и использованию бота](docs/setup-and-usage.md).
