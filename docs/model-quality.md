# Производительность и качество моделей

## Обзор

Бот для прогнозирования акций оценивает эффективность моделей с использованием нескольких метрик, чтобы обеспечить надежные и точные прогнозы. В этом документе описаны используемые метрики, способы их вычисления и стандарты качества, поддерживаемые системой.

## Метрики эффективности

### 1. RMSE (Корень среднеквадратичной ошибки)
- **Определение**: Квадратный корень из средних квадратичных различий между предсказанными и фактическими значениями
- **Формула**: RMSE = √(Σ(Предсказанное - Фактическое)² / n)
- **Интерпретация**: Более низкие значения указывают на лучшую эффективность
- **Применение**: Измеряет величину ошибок прогноза

### 2. MAE (Средняя абсолютная ошибка)
- **Определение**: Среднее значение абсолютных различий между предсказанными и фактическими значениями
- **Формула**: MAE = Σ|Предсказанное - Фактическое| / n
- **Интерпретация**: Более низкие значения указывают на лучшую эффективность
- **Применение**: Измеряет среднюю величину ошибок без учета направления

### 3. MAPE (Средняя абсолютная процентная ошибка)
- **Определение**: Среднее значение абсолютных процентных различий между предсказанными и фактическими значениями
- **Формула**: MAPE = (100/n) × Σ|(Фактическое - Предсказанное)/Фактическое|
- **Интерпретация**: Более низкие значения указывают на лучшую эффективность (выражается в процентах)
- **Применение**: Измеряет точность прогноза в процентах

### 4. AUC (Площадь под кривой)
- **Определение**: Площадь под ROC-кривой для интерпретации бинарной классификации
- **Интерпретация**: Значения, близкие к 1.0, указывают на лучшую эффективность
- **Применение**: Измеряет способность модели различать различные исходы

## Критерии выбора модели

### Основные метрики
Система в первую очередь полагается на эти метрики для выбора модели:

1. **RMSE**: Основная метрика для выбора модели
   - Наиболее чувствительна к большим ошибкам
   - Хороша для измерения общей точности прогноза

2. **MAE**: Вторичная метрика для выбора модели
   - Менее чувствительна к выбросам, чем RMSE
   - Предоставляет среднюю величину ошибки

3. **MAPE**: Третья метрика для выбора модели
   - Предоставляет относительное измерение ошибки
   - Полезна для сравнения между разными акциями

### Композитная оценка
Система вычисляет композитную оценку, объединяя несколько метрик:
- Взвешенная комбинация RMSE, MAE и MAPE
- Более низкие композитные оценки указывают на лучшие модели
- Используется как резервный вариант, когда отдельные метрики противоречат друг другу

## Стандарты качества

### Целевая эффективность
Система стремится к следующим стандартам качества:

- **RMSE**: Менее 5% от средней цены акции
- **MAE**: Менее 3% от средней цены акции
- **MAPE**: Менее 5%
- **AUC**: Более 0.7 (для интерпретации бинарной классификации)

### Пороги эффективности
Модели должны соответствовать минимальным порогам эффективности:

- **Минимально допустимый RMSE**: 10% от средней цены акции
- **Минимально допустимый MAPE**: 15%
- **Минимально допустимый AUC**: 0.5 (порог случайной эффективности)

### Мониторинг эффективности
- Все эффективности моделей регистрируются в CSV-файлах
- Исторические данные об эффективности сохраняются для анализа
- Падение эффективности вызывает оповещения

## Сравнение моделей

### Эффективность статистических моделей
На основе исторических данных, типичные характеристики эффективности:

#### ARIMA
- **Сильные стороны**: Хороша для стационарных данных, захватывает линейные отношения
- **Слабые стороны**: Испытывает трудности с нелинейными паттернами, требует стационарных данных
- **Типичный RMSE**: 2-8% от средней цены
- **Типичный MAPE**: 3-10%

#### ETS
- **Сильные стороны**: Хороша для данных с трендом и сезонностью
- **Слабые стороны**: Предполагает аддитивные/мультипликативные компоненты
- **Типичный RMSE**: 2-7% от средней цены
- **Типичный MAPE**: 3-9%

#### Prophet
- **Сильные стороны**: Автоматически обрабатывает сезонность, праздники, изменения тренда
- **Слабые стороны**: Может быть медленным в обучении, может переобучаться шуму
- **Типичный RMSE**: 1.5-6% от средней цены
- **Типичный MAPE**: 2-8%

### Эффективность нейронных сетей
#### LSTM
- **Сильные стороны**: Отлична для последовательных паттернов, обрабатывает долгосрочные зависимости
- **Слабые стороны**: Вычислительно затратна, требует больше данных
- **Типичный RMSE**: 1-5% от средней цены
- **Типичный MAPE**: 1.5-6%

#### GRU
- **Сильные стороны**: Быстрее LSTM, хороша для последовательных паттернов
- **Слабые стороны**: Может не так хорошо захватывать очень долгосрочные зависимости, как LSTM
- **Типичный RMSE**: 1.2-5.5% от средней цены
- **Типичный MAPE**: 1.8-6.5%

#### RNN
- **Сильные стороны**: Проста и быстра, захватывает последовательные паттерны
- **Слабые стороны**: Испытывает трудности с долгосрочными зависимостями
- **Типичный RMSE**: 2-7% от средней цены
- **Типичный MAPE**: 2.5-8%

## Анализ эффективности

### Сервис оценки моделей
Система включает комплексный сервис оценки моделей, который:

- Сохраняет метрики эффективности в CSV-файлы для сравнения
- Предоставляет функциональность сравнения моделей
- Определяет лучшую модель для каждого тикера
- Вычисляет композитные оценки для общей оценки эффективности
- Генерирует отчеты об эффективности, сравнивающие все модели

### Отчеты об эффективности
Система может генерировать подробные отчеты об эффективности, включая:

- Средние метрики эффективности по всем моделям
- Лучшую модель для каждой метрики
- Рейтинг моделей по эффективности
- Тенденции эффективности со временем
- Сравнительный анализ типов моделей

### Доверительные интервалы
Система предоставляет доверительные интервалы для прогнозов:

- **95% уровень достоверности**: Интервал доверия по умолчанию
- **Метод вычисления**: На основе исторической волатильности
- **Корректировка для волатильных акций**: Более широкие интервалы для акций с >5% ежедневной волатильностью
- **Индикатор надежности**: Доверительные интервалы показывают надежность прогноза

## Обеспечение качества

### Проверка моделей
- Техники перекрестной проверки применяются там, где это уместно
- Выполняется проверка вне выборки
- Эффективность проверяется на невидимых данных
- Стабильность модели оценивается со временем

### Обнаружение снижения эффективности
- Постоянный мониторинг эффективности модели
- Оповещения срабатывают при значительном снижении эффективности
- Автоматическое переобучение при снижении эффективности ниже порога
- Сравнение с базовыми моделями

### Надежность модели
- Последовательность эффективности на разных акциях
- Стабильность эффективности со временем
- Устойчивость к волатильности рынка
- Адаптивность к изменяющимся рыночным условиям

## Бенчмаркинг

### Сравнение с базовым уровнем
- Эффективность сравнивается с простыми эталонами (например, случайное блуждание, наивный прогноз)
- Процент улучшения по сравнению с базовыми моделями
- Статистическая значимость улучшений эффективности

### Промышленные стандарты
- Эффективность сравнивается с промышленными эталонами
- Соответствие стандартам финансового прогнозирования
- Соблюдение регулятивных требований к финансовым прогнозам
