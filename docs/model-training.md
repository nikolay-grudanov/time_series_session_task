# Процесс обучения моделей

## Обзор

Бот для прогнозирования акций реализует несколько машинных обучений и статистических моделей для предсказания цен акций. Система автоматически обучает несколько типов моделей и выбирает лучшую по показателям эффективности.

## Типы моделей

### 1. Нейронные сети

#### LSTM (Длинная краткосрочная память)
- Тип рекуррентной нейронной сети, способной обучаться долгосрочным зависимостям
- Особенно эффективна для последовательных данных, таких как временные ряды
- Реализована с настраиваемыми слоями и скрытыми единицами

#### GRU (Gated Recurrent Unit - Единица с управляемым возвратом)
- Вариант LSTM, более вычислительно эффективный
- Использует меньше вентилей, чем LSTM, сохраняя при этом схожую эффективность
- Хорош для захвата временных паттернов в ценах акций

#### RNN (Рекуррентная нейронная сеть)
- Базовая рекуррентная нейронная сеть для моделирования последовательностей
- Проще, чем LSTM/GRU, но все еще может захватывать временные зависимости
- Подходит для коротких последовательностей

### 2. Статистические модели

#### ARIMA (Авторегрессионная интегрированная скользящая средняя)
- Традиционная модель прогнозирования временных рядов
- Комбинирует авторегрессию, дифференцирование и компоненты скользящего среднего
- Эффективна для стационарных временных рядов

#### ETS (Ошибка, Тренд, Сезонность)
- Модель экспоненциального сглаживания пространства состояний
- Захватывает компоненты ошибки, тренда и сезонности
- Хороша для данных с четкими паттернами тренда и сезонности

#### Prophet
- Разработан Facebook для прогнозирования временных рядов
- Автоматически обрабатывает сезонность, праздники и изменения тренда
- Устойчив к пропущенным данным и выбросам

### 3. Классические ML-модели

#### Random Forest (Случайный лес)
- Ансамблевый метод, использующий несколько деревьев решений
- Хорош для захвата нелинейных зависимостей
- Менее склонен к переобучению, чем отдельные деревья

#### Ridge Regression (Гребневая регрессия)
- Линейная регрессия с L2-регуляризацией
- Помогает предотвратить переобучение с коррелированными признаками
- Хорошо работает с лаговыми признаками

## Процесс обучения

### 1. Подготовка данных
- Исторические данные акций загружаются для запрошенного тикера
- Данные очищаются и предварительно обрабатываются
- Признаки создаются (например, лаговые значения, технические индикаторы)

### 2. Обучение модели
- Каждый тип модели обучается на подготовленных данных
- Обучение учитывает настроенный таймаут (по умолчанию: 5 минут)
- Модели обучаются с подходящими гиперпараметрами

### 3. Оценка эффективности
- Каждая модель оценивается с использованием нескольких метрик:
  - RMSE (Корень среднеквадратичной ошибки)
  - MAE (Средняя абсолютная ошибка)
  - MAPE (Средняя абсолютная процентная ошибка)
  - AUC (Площадь под кривой)

### 4. Выбор модели
- Выбирается модель с лучшими показателями эффективности
- Выбор учитывает несколько метрик для баланса между точностью и устойчивостью
- Выбранная модель используется для прогнозирования

## Гиперпараметры

### Нейронные сети
- Размер скрытого слоя: 50 (настраивается)
- Количество слоев: 2 (настраивается)
- Длина последовательности: 60 дней (настраивается)
- Эпохи обучения: 50 (настраивается)

### ARIMA
- Порядок: (1, 1, 1) по умолчанию (параметры p, d, q)
- Может быть настроен в зависимости от характеристик данных

### ETS
- Тип ошибки: Аддитивный
- Тип тренда: Аддитивный
- Тип сезонности: Аддитивный

### Prophet
- Масштабирование априорной вероятности точек изменения: 0.05
- Масштабирование априорной вероятности сезонности: 10.0

## Конфигурация обучения

### Настройки таймаута
- Максимальное время обучения на модель: 5 минут (300 секунд)
- Предотвращает блокировку бота длительными процессами обучения
- Если достигнут таймаут, выбирается лучшая модель, обученная до этого момента

### Требования к данным
- Минимальные исторические данные: 2 года (настраивается)
- Частота данных: ежедневные закрывающие цены
- Предварительная обработка данных: нормализация и очистка

## Сохранение моделей

- Обученные модели не сохраняются по умолчанию
- Модели переобучаются для каждого нового запроса
- Это обеспечивает захват самых актуальных паттернов

## Настройка

### Добавление новых моделей
Чтобы добавить новый тип модели:

1. Создайте новый класс модели в `src/models/`
2. Реализуйте необходимые методы (обучение, предсказание, оценка)
3. Зарегистрируйте модель в `ModelSelector`
4. При необходимости обновите логику выбора модели

### Изменение гиперпараметров
Гиперпараметры можно изменить в соответствующих файлах моделей:
- Нейронные сети: `src/models/neural_networks.py`
- Статистические модели: `src/models/statistical.py`
- Выбор модели: `src/models/model_selector.py`

## Оптимизация производительности

### Пакетная обработка
- Несколько моделей могут обучаться параллельно, когда это возможно
- Использование ресурсов отслеживается во время обучения

### Ранняя остановка
- Нейронные сети реализуют раннюю остановку для предотвращения переобучения
- Обучение прекращается, если эффективность не улучшается после определенного количества эпох

### Управление памятью
- Модели должным образом удаляются после использования
- Большие наборы данных обрабатываются эффективно для предотвращения проблем с памятью

## Устранение неполадок

### Распространенные проблемы обучения

1. **Ошибки таймаута**: Если модели постоянно превышают таймаут, рассмотрите:
   - Уменьшение объема исторических данных
   - Упрощение архитектуры моделей
   - Увеличение порога таймаута

2. **Проблемы с памятью**: Если обучение не удается из-за памяти:
   - Уменьшите размеры пакетов для нейронных сетей
   - Используйте меньшие длины последовательностей
   - Обрабатывайте данные частями

3. **Плохая эффективность**: Если все модели показывают плохие результаты:
   - Проверьте качество данных и предварительную обработку
   - Рассмотрите создание признаков
   - Убедитесь, что данные подходят для прогнозирования

## Мониторинг и ведение журналов

- Прогресс обучения моделей записывается в `logs/requests.log`
- Метрики эффективности хранятся для анализа
- Время обучения записывается для оптимизации
