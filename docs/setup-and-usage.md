# Руководство по настройке и использованию бота

## Предварительные требования

- Python 3.12
- Менеджер пакетов uv
- Токен Telegram-бота (от BotFather)

## Установка

### 1. Клонирование репозитория

```bash
git clone <ссылка-на-репозиторий>
cd time_series_session_task
```

### 2. Установка зависимостей

Этот проект использует `uv` для управления зависимостями:

```bash
# Установка зависимостей
uv sync

# Или если вы предпочитаете pip
pip install -r requirements.txt
```

### 3. Настройка окружения

Создайте файл `.env` в корне проекта со следующими переменными:

```
TELEGRAM_BOT_TOKEN=ваш_токен_бота_здесь
```

Вы можете получить токен бота, отправив сообщение [@BotFather](https://t.me/BotFather) в Telegram и выполнив следующие шаги:
1. Начните чат с BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте токен, предоставленный BotFather

## Запуск бота

### 1. Запуск бота

```bash
python src/main.py
```

### 2. Использование бота

После запуска бота вы можете взаимодействовать с ним в Telegram:

1. Найдите своего бота в Telegram (поиск по имени пользователя)
2. Отправьте команду `/start`, чтобы получить приветственное сообщение
3. Отправьте сообщение в формате: `<СИМВОЛ ТИКЕРА> <СУММА ИНВЕСТИЦИЙ>`

#### Пример использования:
```
AAPL 1000
```

Это приведет к:
- Загрузке исторических данных для Apple Inc. (AAPL)
- Обучению нескольких моделей прогнозирования
- Выбору лучшей модели по эффективности
- Генерации 30-дневного прогноза
- Предоставлению торговых рекомендаций
- Расчету потенциальной прибыли

### 3. Поддерживаемые форматы

- **Символы тикеров**: 1-5 заглавных букв (например, AAPL, GOOGL, TSLA, BRK.B)
- **Сумма инвестиций**: От $1 до $1,000,000

## Параметры конфигурации

### Переменные окружения

| Переменная | Описание | Обязательная |
|------------|----------|--------------|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота от BotFather | Да |

### Настройки

Конфигурация бота находится в файле `src/config/settings.py`:

- `MODEL_TRAINING_TIMEOUT`: Максимальное время (в секундах) для обучения модели (по умолчанию: 300 секунд)
- `FORECAST_DAYS`: Количество дней для прогноза (по умолчанию: 30)
- `MIN_INVESTMENT_AMOUNT`: Минимальная сумма инвестиций (по умолчанию: 1)
- `MAX_INVESTMENT_AMOUNT`: Максимальная сумма инвестиций (по умолчанию: 1,000,000)
- `HISTORICAL_YEARS`: Количество лет исторических данных для использования (по умолчанию: 2)

## Устранение неполадок

### Распространенные проблемы

1. **Бот не отвечает**: Проверьте, что TELEGRAM_BOT_TOKEN указан правильно и бот запущен
2. **Неверный тикер**: Убедитесь, что символ тикера действителен и в правильном формате
3. **Ограничение скорости**: Бот реализует ограничение скорости для вызовов Yahoo Finance API
4. **Таймаут обучения модели**: Если модели требуют слишком много времени для обучения, измените настройки таймаута

### Журналы

Бот записывает все запросы и ошибки в `logs/requests.log`. Вы можете проверить этот файл для устранения неполадок:

```bash
tail -f logs/requests.log
```

## Развертывание

### Развертывание в продакшене

Для развертывания в продакшене рассмотрите следующие варианты:

1. Использование менеджера процессов, такого как `systemd` или `supervisor`
2. Настройка надлежащего ведения журналов и мониторинга
3. Использование переменных окружения для конфигурации
4. Реализация проверок работоспособности

### Пример файла службы systemd

Создайте `/etc/systemd/system/stock-forecast-bot.service`:

```
[Unit]
Description=Telegram-бот для прогнозирования акций
After=network.target

[Service]
Type=simple
User=ваш-пользователь
WorkingDirectory=/путь/к/проекту
ExecStart=/путь/к/venv/bin/python src/main.py
Restart=always
EnvironmentFile=/путь/к/проекту/.env

[Install]
WantedBy=multi-user.target
```

Затем включите и запустите службу:

```bash
sudo systemctl daemon-reload
sudo systemctl enable stock-forecast-bot
sudo systemctl start stock-forecast-bot
```
